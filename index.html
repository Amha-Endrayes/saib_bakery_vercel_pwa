Offline-First Local Persistence Active

All counter sales, oven batches, and flour inventory levels are automatically saved locally on the phone. If internet drops during peak hours, sales queue locally and sync automatically when connectivity returns.

1. Install on Android & iPhone (Shop Phones)
  • Android (Chrome): Tap the browser menu (⋮) → "Add to Home Screen" / "Install App" for full-screen one-handed POS mode.
  • iPhone (Safari): Tap the Share button → "Add to Home Screen".
2. Deploy to Vercel in 30 Seconds

Use the downloadable saib_bakery_vercel_pwa.zip project bundle (includes vercel.json, manifest.json, and offline Service Worker sw.js): push to GitHub and import into Vercel, or run npx vercel --prod.
